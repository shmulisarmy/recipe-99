Why Convex generates the bridge

You noticed two apparent indirections. They are the same design idea appearing twice: local objects cannot cross runtime boundaries, so Convex crosses those boundaries with typed names.

Convex code generation turns runtime addresses into editor-checked TypeScript.

Your first observation: why "numbers"?

defineTable(...) produces a schema-definition value. It is used inside defineSchema({ numbers }) when Convex builds the data model. It is not a live table object or database connection.

Inside getAllNumbers, ctx.db is the live database interface for that particular query execution. It identifies the deployed table by name:

return await ctx.db.query("numbers").collect();

The string is less “stringly typed” than it looks

Because you import query from ./_generated/server, TypeScript knows the tables from your exported schema. After code generation, misspelling "numbers" as "numbres" should produce an editor/typecheck error.

Your second observation: why generated api?

The browser and Convex backend are different JavaScript runtimes. Importing the backend implementation into the browser would be the wrong direction: the browser cannot supply ctx.db, and backend code should not be bundled into the frontend.

Convex instead derives a public name from the backend file and export:

convex/data.ts + export getAllNumbers
                  ↓
       api.data.getAllNumbers
                  ↓
          "data:getAllNumbers"

The generated value is a FunctionReference. Its TypeScript type carries “this is a query,” its argument shape, and its return type. At runtime, it tells the Convex client which deployed function to call. Convex documents this file-and-export naming rule in its query guide and the reference object in its FunctionReference API.

What useQuery adds

const numbers = useQuery(api.data.getAllNumbers, {});

useQuery combines the typed address with arguments and opens a subscription. The query runs on Convex, not in the component. Queries are cached and subscribable; when relevant database data changes, Convex updates subscribed clients. Convex functions overview.
