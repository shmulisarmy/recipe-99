Recipe-99 reference · two runtime bridges

Names cross boundaries. Types make them safe.

Convex does not pass your local schema objects or backend function objects across runtimes. It generates typed names for both boundaries.

Bridge 1: schema → database runtime

// schema construction time
const numbers = defineTable({ name_: v.string() });
export default defineSchema({ numbers });

// query execution time
ctx.db.query("numbers")

numbers is a schema-definition value. "numbers" is the deployed table name. The generated ctx.db type restricts that string to tables in the exported schema.

Bridge 2: backend module → browser runtime

// convex/data.ts
export const getAllNumbers = query(/* ... */);

// browser code
api.data.getAllNumbers
// means the registered address "data:getAllNumbers"

The generated API member is a FunctionReference: a typed address containing the query kind, argument type, and return type. It is not the backend implementation.
