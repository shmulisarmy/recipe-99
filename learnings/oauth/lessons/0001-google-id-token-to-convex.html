Recipe-99 OAuth · Lesson 1

From Google login to a Convex-owned pantry

The browser proves identity with a short-lived token. Convex verifies that proof and decides which pantry rows the request may access.

1. Google Authenticates the account and signs an ID token.
2. SolidJS Gives the token to the existing Convex client connection.
3. Convex Checks issuer, signature, expiry, and client-ID audience.
4. Pantry query Uses the verified tokenIdentifier as owner.

Two identifiers, two jobs

Google’s subject is the account’s OAuth ID for this issuer. Recipe-99 exposes it through getCurrentUserOAuthId so the identity can be inspected. Pantry ownership uses Convex’s tokenIdentifier, which includes provider context and is the safer cross-provider database key.

The authorization rule: a browser never supplies the pantry owner ID. Every protected Convex function calls ctx.auth.getUserIdentity() and derives the owner on the server.

Why reload no longer means login again

The first implementation kept the ID token only in a module variable, which disappears on reload. Recipe-99 now keeps the same short-lived token in sessionStorage, checks its audience and expiry, and reconnects Convex with it after reload. Sign-out removes it.

This is deliberately not a permanent session. Google ID tokens normally expire quickly, and the app does not store a Google refresh token or client secret. A longer-lived production session would normally use a server-managed auth system.

Troubleshooting map

  • Origin error: confirm Google allows exactly http://localhost:3000.
  • Convex says unauthenticated: confirm convex/auth.config.ts has Google’s issuer and the same client ID.
  • Reload signs out immediately: inspect token expiry and whether session storage was cleared.
  • Wrong pantry appears: inspect tokenIdentifier ownership, never trust a client-provided ID.
Retrieval check: without looking above, explain why the public Google client ID is safe in frontend code, but the client secret is not. Then explain why subject is displayed while tokenIdentifier owns pantry rows.
